# Palisad: Карта муралов Вологды

Интерактивная карта фестиваля стрит-арта «Палисад». Проект автоматически собирает данные о муралах из постов VK и отображает их на карте.

## Основные возможности

- **Автоматический парсинг**: Скрипт `src/parser.js` извлекает адреса и авторов из постов.
- **Геокодирование**: Автоматическое определение координат через Nominatim API.
- **Интерактивная карта**: Отображение всех найденных арт-объектов с фотографиями.

## Структура проекта

- `src/addresses.json` — основная база данных объектов (название, координаты, фото, автор).
- `src/authors.json` — база данных художников.
- `src/parser.js` — скрипт для обновления баз данных.
- `images/photos/` — папка со всеми скачанными фотографиями муралов.
